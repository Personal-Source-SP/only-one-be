# English Learning Extraction

## Overview

Use this skill when authoring concept, plan, or archive documents to extract high-leverage technical English structures, idiomatic phrases, and architectural terminology into persistent learning documents (`only-one/learn/<topic>.md`).

## Workflow

1. Identify 2–4 high-signal engineering expressions or grammar patterns used in the task or technical context.
2. Structure each entry with:
   - Pattern name or expression.
   - Concise and accurate Vietnamese meaning (`Meaning (VI)`).
   - Grammar/syntax breakdown (`Grammar / Usage`).
   - Context-grounded engineering example sentence (`Engineering Example`).
3. Append unique, non-duplicate entries to the appropriate topic file in `only-one/learn/`.
